## ✨ Обзор возможностей

### 🧠 AI-ассистент
Интеграция с 6 AI-провайдерами (OpenAI, DeepSeek, Tongyi Qianwen, Zhipu AI, Moonshot, SiliconFlow) с поддержкой многомодового взаимодействия.

| Режим | Описание |
|------|-------------|
| AI-чат | Прямое общение в правой панели, поддержка потокового вывода, рендеринг Markdown, сохранение/загрузка истории; доступно отдельное окно AI-ассистента |
| AI-анализ процесса | Правый клик по процессу → AI-анализ, получение оценки безопасности и рекомендаций |
| AI-сканирование процессов | Сканирование всех процессов одним кликом, выбор уровня сканирования, AI определяет подозрительные/ненужные процессы, поддержка пакетного завершения |
| AI-пакетное переименование | Опишите требования на естественном языке, AI автоматически генерирует сопоставления имён файлов, поддержка наложения с другими правилами переименования |

Панель AI-ассистента включает встроенный ConPTY-терминал с поддержкой нескольких сессий. Когда AI выполняет команды, они автоматически запускаются в терминале с возвратом результатов.

### 🌐 Многоязычный интерфейс
Поддерживает переключение между русским и английским языками, файлы локализации находятся в каталоге `lang/`, легко расширяется для добавления новых языков. См. раздел «Многоязычный интерфейс» в [описании возможностей](https://github.com/gyx114/PowerBox/wiki/Feature-Details).

### 📋 Основные инструменты

| Инструмент | Описание |
|------------|-------------|
| Диспетчер процессов | Перечисление процессов, отображение CPU/памяти, поддержка сортировки/фильтрации (включая регулярные выражения), завершение процесса, поиск файла, AI-анализ |
| Менеджер автозагрузки | Просмотр/Добавление/Удаление/Включение/Отключение записей автозагрузки в реестре, двойной щелчок для копирования пути, поддержка добавления записей на уровне машины |
| История буфера обмена | Запись последних 10 текстовых записей, двойной щелчок для вставки, последовательные дубликаты автоматически удаляются |
| Инструмент работы с окнами | Поиск окна (Ctrl+Alt+D), закрепление поверх всех окон (поддержка нескольких окон), регулировка прозрачности (10%–100%), принудительное закрытие, сохранение скриншота; автоматическое сохранение истории поиска |
| Файловый менеджер | Перетаскивание файлов для создания копий (настраиваемое имя), переименование, удаление (в корзину), копирование, перемещение; перетаскивание папки для открытия пакетного переименования |
| Git-инструментарий | 20 предустановленных команд, поддержка пользовательского списка (config.ini [GitCommands]), автоматическое определение ветки репозитория, AI-помощь в генерации команд, быстрый запуск Git Bash, отдельное окно результатов Git-команд |

### 🛠 Инструментальные окна

| Инструмент | Описание |
|------------|-------------|
| Генератор QR-кодов | Создание QR-кодов из текста, поддержка копирования в буфер обмена и сохранения в PNG/BMP (белое поле 4px) |
| OCR экрана | Снимок выделенной области, распознавание текста через Windows OCR, поддержка китайского/английского/японского/корейского языков, поддержка перевода через MyMemory API (6 языковых пар) |
| Пакетное переименование | Префикс/Суффикс/Замена/Нумерация/Регулярное выражение/Удаление по совпадению, поддержка правил игнорирования и отслеживания, поддержка AI-переименования, отмены и переименования папок |
| Стикеры | Заметки поверх всех окон, свёртывание/развёртывание (двойной щелчок по заголовку), кнопка X для свёртывания/выхода, содержимое автоматически сохраняется в папку конфигурации |
| Предпросмотр Markdown | Раздельный редактор + предпросмотр в реальном времени, CSS в стиле GitHub (marked.js), перетаскиваемый разделитель, поддержка открытия .md файлов |
| Конвертация кодировок | Автоопределение кодировки (UTF-8/UTF-8 BOM/UTF-16LE/UTF-16LE BOM/UTF-16BE/GBK/Big5/Shift-JIS/Latin-1), поддержка пакетной конвертации |
| Менеджер контекстного меню | Сканирование/Включение/Отключение элементов контекстного меню, поддержка 28+ сценариев, 14 предустановок расширений + пользовательские, AI-разбор непереведённых элементов, поддержка переключения классического меню Win11 |
| Переменные окружения | Просмотр/Редактирование/Экспорт системных/пользовательских переменных окружения, редактор PATH (независимое редактирование строк), автоматическое резервное копирование перед изменением |
| Просмотр блокировок файлов | Перетащите файл для просмотра блокирующих процессов (Restart Manager API), поддержка завершения процесса/всех процессов/перехода в папку процесса |
| Быстрый запуск | Настраиваемые кнопки быстрого доступа (до 36), поддержка 5 типов: исполняемый файл/папка/URL/другой файл/горячая клавиша; для исполняемых файлов можно назначить активационные горячие клавиши; тип «горячая клавиша» может имитировать комбинации клавиш; включает диалог управления, поддержка сортировки перетаскиванием, быстрое добавление файлов/папок перетаскиванием |
| Пользовательские горячие клавиши | Глобальные горячие клавиши (показать/скрыть главное окно, поиск окна) настраиваются в параметрах с диалогом захвата горячих клавиш; элементы быстрого запуска поддерживают активационные горячие клавиши и имитацию нажатий |
| ConPTY-терминал | Встроенный терминал на панели AI-ассистента, поддержка нескольких сессий, переключение по горизонтальной панели вкладок (Ctrl+Tab/колёсико мыши/средняя кнопка для закрытия), AI автоматически запускает команды в новой вкладке терминала |
| Отдельное окно AI-ассистента | Отдельное окно AI-ассистента, которое можно использовать независимо от главного окна, с полным набором функций чата, терминала и управления историей |

### ⌨️ Горячие клавиши

| Клавиши | Функция |
|----------|----------|
| `Ctrl+Alt+Space` | Глобальная горячая клавиша, показать/скрыть главное окно (настраивается в параметрах) |
| `Ctrl+Alt+D` | Режим поиска окна (настраивается в параметрах) |
| `Alt+1` ~ `Alt+6` | Переключение вкладок левой боковой панели |
| `F5` | Обновить текущий список |
| `Del` | Завершить выбранный процесс |
| `Enter` | Отправить сообщение в AI-чат (когда фокус на панели AI). `Shift+Enter` для новой строки. |

## 📥 Установка

### Загрузка релизов
Перейдите на [страницу релизов](https://github.com/gyx114/PowerBox/releases), чтобы загрузить последнюю версию `PowerBox.zip`, распакуйте и используйте сразу (портативное ПО, установка не требуется). В архив входят `PowerBox.exe` и папка `lang/` с языковыми файлами — всё готово к работе.

### Сборка из исходников
Требуется Visual Studio 2022 (или новее) с рабочей нагрузкой «Разработка классических приложений на C++» (включая компоненты MFC).

```bash
git clone https://github.com/gyx114/PowerBox.git
cd PowerBox
msbuild MFCApplication1/MFCApplication1.vcxproj /p:Configuration=Release /p:Platform=x64
```

Результат сборки находится в `x64/Release/PowerBox.exe`. После сборки скопируйте папку `MFCApplication1/lang/` из исходников в каталог с исполняемым файлом; в противном случае программа будет использовать встроенный русскоязычный интерфейс и не сможет переключать языки.

## 🛠 Технологический стек

| Категория | Технология |
|----------|------------|
| Язык | C++20 |
| UI-фреймворк | MFC (Microsoft Foundation Classes) |
| AI-интеграция | WinHTTP + 6 AI-провайдеров (OpenAI, DeepSeek, Tongyi Qianwen, Zhipu AI, Moonshot, SiliconFlow) |
| QR-коды | Nayuki QR Code Generator |
| OCR | Windows OCR API (Windows.Media.Ocr) + MyMemory Translation API |
| Markdown | Элемент WebBrowser + marked.js (CSS в стиле GitHub) |
| Терминал | ConPTY (Windows Pseudo Console) |
| Многоязычность | INI-файлы (UTF-16 LE) + встроенные значения по умолчанию, поддержка переключения русского/английского, языковые файлы в каталоге `lang/` |
| Сборка | Visual Studio 2022 + MSBuild |
